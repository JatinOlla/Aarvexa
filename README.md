# Aarvexa 🏥

Aarvexa is a modern hospital management web application designed to provide a simple and user-friendly healthcare dashboard.

## Features

- Patient dashboard
- Doctor information
- Appointment booking
- Medicine information
- Medical records
- Notifications
- Emergency assistance

## Technologies Used

- HTML
- CSS
- JavaScript

## Project

This project was created as a college project to demonstrate basic web development and JavaScript functionality.
